## Install the plugin

<Steps>
  <Step title="Download the jar">
    Get `PerPlayerKit-x.x.x.jar` from [Modrinth](https://modrinth.com/plugin/perplayerkit), [SpigotMC](https://www.spigotmc.org/resources/perplayerkit.121437/), or [Hangar](https://hangar.papermc.io/noah32/PerPlayerKit).
  </Step>

  <Step title="Stop the server">
    Shut it down fully.
  </Step>

  <Step title="Put the jar in the plugins folder">
    Copy the <Tooltip tip="The plugin file you drop into your server's plugins folder.">jar</Tooltip> into `plugins/`.
  </Step>

  <Step title="Start the server">
    The plugin creates `plugins/PerPlayerKit/`.
  </Step>

  <Step title="Stop the server again">
    A running server overwrites edits to `config.yml` when it saves.
  </Step>

  <Step title="Pick a database">
    Set `storage.type` in `plugins/PerPlayerKit/config.yml`. See [below](#choose-a-database).
  </Step>

  <Step title="Start the server">
    The plugin connects and finishes setup.
  </Step>
</Steps>

## What the plugin creates

<Tree>
  <Tree.Folder name="plugins/" defaultOpen>
    <Tree.File name="PerPlayerKit-x.x.x.jar" />
    <Tree.Folder name="PerPlayerKit/" defaultOpen>
      <Tree.File name="config.yml" />
      <Tree.Folder name="lang/" />
      <Tree.Folder name="backups/" />
      <Tree.File name="database.db" />
    </Tree.Folder>
  </Tree.Folder>
</Tree>

| | |
| --- | --- |
| `config.yml` | All settings. |
| `lang/` | One file per language. |
| `backups/` | Automatic backups. SQLite and YAML only. |
| `database.db` | SQLite only. |

## Choose a database

| `storage.type` | Use it for |
| -------------- | ---------- |
| `sqlite` | A single server. No setup, no password. |
| `mysql`, `postgresql`, `redis` | A network that shares kits between servers. |

<Tabs>
  <Tab title="SQLite (recommended)">
    ```yaml config.yml
    storage:
      type: sqlite
    ```

    Created at `plugins/PerPlayerKit/database.db` on the next start.
  </Tab>

  <Tab title="MySQL">
    Works with MariaDB too.

    ```yaml config.yml
    storage:
      type: mysql
      mysql:
        host: localhost
        port: '3306'
        dbname: kitdatabase
        username: username
        password: pa55w0rd
        use-ssl: false
        maximum-pool-size: 10
    ```

    Create the database first; the plugin makes its own tables.
  </Tab>

  <Tab title="PostgreSQL">
    ```yaml config.yml
    storage:
      type: postgresql
      postgresql:
        host: localhost
        port: '5432'
        dbname: kitdatabase
        username: username
        password: pa55w0rd
        use-ssl: false
        maximum-pool-size: 10
    ```

    Create the database first; the plugin makes its own tables.
  </Tab>

  <Tab title="Redis">
    ```yaml config.yml
    storage:
      type: redis
      redis:
        host: localhost
        port: 6379
        password: pa55w0rd
    ```
  </Tab>
</Tabs>

<Warning>
  Do not use the `yml` storage type on a real server. It is slow and can lose data.
</Warning>

## Optional plugins

| Plugin | What it adds |
| ------ | ------------ |
